# Sprint 0 manual evidence

These reports are completed by a human on controlled test hardware. Prototype type-checks are recorded in the tracker, but they do not satisfy hardware, TCC, focus or application-compatibility gates.

- [P0-03 Accessibility spike](p0-03-ax-spike.md)
- [P0-04 Event Tap spike](p0-04-event-tap-spike.md)
- [P0-05 Screen geometry spike](p0-05-screen-geometry-spike.md)

Record only permission state, app bundle/version, hardware/OS, action ID, geometry and redacted error codes. Never record raw keystrokes, window/document titles, clipboard data or screenshots containing private content.
